# processRepairOrder 改进后复杂度说明

控制流图保留原有 5 个判定节点，并新增 2 个普通处理节点，不增加新的判定节点。

- 成功路径：持久化成功？ → 是 → 更新工单状态为“待验收” → 返回结果并结束。
- 异常回滚路径：持久化成功？ → 否/异常 → 回滚本次变更并返回失败结果 → 返回结果并结束。
- 未完成维修路径：维修完成？ → 否 → 记录未完成原因，工单状态保持“处理中” → 返回结果并结束。

复杂度重新计算如下：

- 节点数：n = 12
- 边数：e = 16
- 判定节点数：5（身份校验、维修状态、维修完成、维修记录完整、持久化成功）
- 判定节点法：V(G) = 5 + 1 = 6
- 边点差法：V(G) = e - n + 2 = 16 - 12 + 2 = 6
- 区域数法：V(G) = 6

三种方法计算结果一致，因此改进后的环形复杂度为 V(G) = 6。
